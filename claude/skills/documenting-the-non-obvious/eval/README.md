# Eval

`brief.md` is a task plus a deliberately over-complete fact dump; `rubric.md`
is what the author accepted and rejected; `gold.md` is the doc they kept.

To rerun: five fresh Opus subagents with no other context read SKILL.md and
brief.md and write the doc; grade each by hand against the rubric. Always run
a no-skill control alongside. `results-2026-09-06.md` has the baseline and the
three iterations that produced the current SKILL.md.
