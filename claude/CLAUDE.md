* Prefer CLI long options (--silent) over short options (-s)
* Instead of "load-bearing", use "required" (or prerequisite / read by /
  enforced / crucial) plus the dependent and what breaks without it: "required by
  configure-maven-proxy.py", "the scripts refuse to run without it". Do not
  substitute essential/critical/crucial -- they assert importance the same way.
  Applies to prose, code comments, commit messages and docs.
